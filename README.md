# ConsoleApp15 — Работа с файлами в C#

Консольное приложение на C# (.NET 10) с интерактивным меню. Реализует 6 заданий по работе с файловой системой: копирование, шифрование, перемещение, сериализация, поиск дубликатов и транзакционная запись.

Навигация стрелками ↑↓, выбор — Enter. Все выходные файлы сохраняются в папку `Korzina/`.

## Задания

### Задание 5 — Копировальщик с прогрессом (`NumeroCinco.cs`)

Пользователь вводит путь к исходному файлу и имя копии (или оставляет пустым — тогда к имени добавляется суффикс `_copy`). Копирование выполняется блоками по **4096 байт** через два `FileStream` (исходный на чтение, целевой на запись). На каждом блоке обновляется строка прогресса в консоли через `\r` — без прокрутки. По завершении выводится время выполнения через `Stopwatch`. Результат сохраняется в `Korzina/`.

```
Прогресс: 73.21%  (748544/1022341 байт)
Копирование завершено за 0.04 секунд.
```

---

### Задание 6 — XOR-шифрование (`NumeroSeis.cs`)

Пользователь вводит путь к файлу и ключ-строку. Файл читается целиком как массив байт (`File.ReadAllBytes`), затем каждый байт XOR-ится с байтом ключа по формуле `data[i] ^= keyBytes[i % keyBytes.Length]` — ключ циклически повторяется. Зашифрованный файл сохраняется как `<имя>.enc` в `Korzina/`. Если на вход подан файл с расширением `.enc` — расшифровывает его обратно (XOR симметричен: одна и та же операция шифрует и расшифровывает). Ключ передаётся как строка UTF-8.

```
Файл успешно зашифрован: Korzina\test 6.txt.enc
```

### Задание 7 — Менеджер фотоархива (`NumeroSiete.cs`)

Пользователь вводит путь к папке (по умолчанию `DataTests/task7_photos`). Программа рекурсивно обходит её через `Directory.GetFiles(..., SearchOption.AllDirectories)` и находит все файлы с расширениями `.jpg`, `.jpeg`, `.png`, `.bmp`. Выводит список найденных изображений с их расширениями и запрашивает подтверждение (`да`/`нет`). После подтверждения перемещает файлы в `Korzina\Anapa 2007\` через `File.Move`. Если файл с таким именем уже существует — автоматически добавляет счётчик: `photo (1).jpg`, `photo (2).jpg` и т.д. Тестовая папка содержит вложенные подпапки `отпуск/`, `разное/`, `старые/` — посторонние файлы (`readme.txt`, `data.csv`, `notes.docx`) игнорируются.

```
Файл: IMG_001.jpg | Расширение: .jpg
Найдено изображений: 5
Переместить? (да / нет): да
✓ Перемещено: IMG_001.jpg
```

### Задание 8 — Сериализация книг в JSON и XML (`NumeroOcho.cs`)

Класс `Book` с полями `Title`, `Author`, `Year`, `Pages`. При запуске загружает коллекцию из `books.json` или `books.xml` на выбор пользователя. Внутреннее меню позволяет добавлять книги (ввод с консоли), просматривать список и сохранять — одновременно в оба формата. JSON сериализуется через `System.Text.Json` с отступами (`WriteIndented = true`), XML — через `XmlSerializer` в `FileStream`. Файлы хранятся в `Korzina/books.json` и `Korzina/books.xml`.

```
1. Мастер и Маргарита - Булгаков (1967 г.), 480 стр.
2. 1984 - Оруэлл (1949 г.), 328 стр.
Данные успешно сохранены в books.json и books.xml
```

### Задание 9 — Поиск дубликатов по MD5 (`NumeroNueve.cs`)

Двухэтапный алгоритм для эффективного поиска. **Этап 1:** все файлы группируются по размеру (`FileInfo.Length`) — группы с одним файлом сразу отбрасываются без вычисления хеша. **Этап 2:** для оставшихся групп вычисляется MD5 через `MD5.ComputeHash(FileStream)` и результат переводится в hex-строку. Файлы с одинаковым хешем — дубликаты. Результат пишется в `Korzina/duplicates.txt`: дата сканирования, путь к папке, группы с хешем и путями к каждому файлу. Тестовая папка `task9_files/` содержит намеренно дублирующиеся файлы: `report_q1.txt` = `report_q1_copy.txt`, `fileA.dat` = `fileB.dat`, `picture.bin` = `picture_bak.bin`.

```
Группа 1 (хеш: a3f2c1...)
  docs\report_q1.txt
  backup\report_q1_copy.txt

Найдено групп дубликатов: 3
Отчет сохранен: Korzina\duplicates.txt
```

### Задание 10 — Транзакционная запись (`NumeroDiez.cs`)

Класс `SafeFileWriter` реализует безопасную запись по трёхшаговой схеме с защитой от сбоев:

1. **BACKUP** — если файл существует, копируется в `<файл>.bak`
2. **TMP** — новые данные пишутся во временный файл `<файл>.tmp`
3. **REPLACE** — атомарная замена через `File.Replace(tmp, target, bak)`

Каждый шаг фиксируется в лог-файле `transactions.log` с меткой времени и статусом (`START`, `BACKUP_CREATED`, `TMP_WRITTEN`, `SUCCESS`, `ERROR`). При запуске метод `RecoverIfNeeded()` читает последнюю строку лога: если там `START`, `TMP_WRITTEN` или `ERROR` — значит предыдущая транзакция не завершилась, и файл восстанавливается из `.bak`. Временный `.tmp` гарантированно удаляется в блоке `finally`.

```
Обнаружена незавершенная транзакция. Выполняется восстановление...
Восстановление из резервной копии выполнено.
Транзакция успешно завершена.
```

## Как запустить

1. Открыть решение `ConsoleApp15.slnx` в Visual Studio 2022
2. Пересобрать (`Ctrl+Shift+B`)
3. Запустить (`F5`)
4. Выбирать задание стрелками, подтверждать Enter

> ⚠️ Пути к `Korzina/` и `DataTests/` захардкожены под локальную машину. При запуске на другом компьютере исправить метод `GetKorzinaPath()` в каждом файле задания.
